# The Arthur — financial model

A single-page working model for the North Palm Beach motel-to-lodge capstone. The first tab is the original three cases, which share one purchase price. The second tab tests 50, 55, and 60 larger rooms, with a restaurant and bar shell reserved for a later phase.

This is a planning model for the class project, not an appraisal or a loan quote. The repository is public so GitHub Pages can host it on a free account.
